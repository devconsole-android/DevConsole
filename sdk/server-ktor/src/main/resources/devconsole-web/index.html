Open DevConsole on the device → More, then open the dashboard URL.
How to connect

The unified event tail appears here once this browser is connected. On the device, open DevConsole → More — it shows the dashboard URL, and a code only when SESSION_CODE is enabled.

  • Open mode accepts the bare http://host:port/ address. In SESSION_CODE mode, the #code= fragment is the credential.
  • Emulator or firewalled device? Forward the port first: adb forward tcp:8080 tcp:8080 — 8080 is only the first port tried; the server takes the next free one up to 8099, so confirm the exact address on the device's More screen.
  • Open the URL directly, or scan the QR/paste the code when SESSION_CODE is enabled.
